An unofficial Foundry VTT conversion of **The Sablewood Messengers**, the free Daggerheart
Quickstart Adventure by Darrington Press — a complete Tier 1 one-shot with ready-to-run
scenes, pregens, NPCs, music, and journal entries.

The original adventure PDF is available for free from Darrington Press:
[Sablewood-05-20-25.pdf](https://www.daggerheart.com/wp-content/uploads/2025/05/Sablewood-05-20-25.pdf)

## Requirements

- Foundry VTT v14 (minimum/verified)
- The [Daggerheart](https://github.com/Foundryborne/daggerheart/) game system

Recommended:

- [Click to Scene](https://github.com/cosmosaurs/click-to-scene)
- [Daggerheart Enhanced UI](https://github.com/Artieficr/daggerheart-enhanced-ui)
- [Daggerheart Spotlight Carousel](https://github.com/pasoktcm/daggerheart-spotlight-carousel)
- [Dice So Nice](https://gitlab.com/riccisi/foundryvtt-dice-so-nice)
- [Dice Tray](https://github.com/mclemente/fvtt-dice-tray)

## How To

1. In Foundry's **Add-on Modules** tab, install via manifest URL:<br>
   `https://github.com/Artieficr/sablewood-messengers/releases/latest/download/module.json`<br>
   (or install manually and drop the repo contents into `Data/modules/artieficr-the-sablewood-messengers/`)
2. Activate the module in your Daggerheart world
3. Navigate to the Compendiums tab
4. Open "The Sablewood Messengers" adventure compendium
5. Import the adventure to your world
6. Follow the adventure content and guidance provided

## Features

- Complete Tier 1 adventure content
- Ready-to-use scenes, PC pregens, NPCs, music playlists and comprehensive journal entries
- no AI used for creation of this module
